# Shared Agent Rules

1. Treat the repository as the source of truth, not private chat history.
2. Read this file, PROJECT_CONTEXT.md, TASKS.md, DECISIONS.md, and HANDOFF.md before work.
3. Inspect Git status, recent changes, and relevant implementation before editing.
4. Preserve uncommitted work. Never reset, overwrite, or discard changes without approval.
5. Work on the assigned task; avoid unrelated refactors.
6. Do not change architecture, public APIs, database schemas, or dependencies without a clear reason and documented decision.
7. Never commit secrets, tokens, credentials, private keys, or real .env files.
8. Add/update tests for changed behavior and run relevant tests/builds.
9. Report only tests actually run and results actually observed.
10. Before handing off, update TASKS.md and HANDOFF.md. Update PROJECT_CONTEXT.md or DECISIONS.md when needed.
11. Report changed files, behavior, test results, known issues, and one exact next step.
12. Ask before destructive actions or irreversible operations.
